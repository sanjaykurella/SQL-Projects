# Dashboard

This folder contains interactive dashboards developed for the Hyderabad Metro Ridership & Operations Analytics project.

## Dashboard Tools

- Microsoft Excel
- Microsoft Power BI
- Tableau

## Dashboard Objectives

- Monitor passenger ridership
- Track revenue performance
- Analyze station-wise traffic
- Identify peak travel hours
- Evaluate operational KPIs
- Support business decision-making

## Dashboard Files

- Excel Dashboard
- Power BI Dashboard
- Tableau Dashboard
