# Hyderabad Metro Ridership & Operations Analytics

## Project Overview

This project analyzes Hyderabad Metro ridership and operational data using SQL to generate actionable business insights for improving passenger experience, operational efficiency, and revenue.

## Business Problem

Hyderabad Metro serves thousands of passengers every day. Metro management requires data-driven insights to understand passenger behavior, identify peak travel periods, optimize train schedules, and improve station performance.

## Project Objectives

- Analyze daily passenger traffic
- Identify the busiest metro stations
- Measure revenue trends
- Analyze peak travel hours
- Evaluate route performance
- Support operational decision-making

## Tech Stack

- PostgreSQL
- SQL
- Microsoft Excel
- Power BI
- Tableau
