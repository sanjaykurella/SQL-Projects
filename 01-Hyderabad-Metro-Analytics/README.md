# Hyderabad Metro Ridership & Operations Analytics
## Business Problem

Hyderabad Metro Rail Limited (HMRL) wants to improve operational efficiency, enhance passenger experience, optimize train schedules, and maximize revenue through data-driven decision-making.

This project analyzes Hyderabad Metro operational data using SQL to identify passenger trends, revenue patterns, station performance, and operational insights that support better business decisions.

---

## Project Objectives

- Analyze passenger ridership trends
- Identify peak and off-peak travel hours
- Evaluate station-wise performance
- Measure revenue generated by ticket types
- Analyze route performance
- Monitor operational KPIs
- Generate business insights for decision-makers
