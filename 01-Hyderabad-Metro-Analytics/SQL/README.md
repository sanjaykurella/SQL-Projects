# SQL Scripts

This folder contains all SQL scripts used in the Hyderabad Metro Ridership & Operations Analytics project.

## Files

- schema.sql
- insert_data.sql
- data_cleaning.sql
- business_queries.sql
- views.sql
- stored_procedures.sql (if applicable)

## Purpose

These SQL scripts are used to create the database, clean the data, perform business analysis, and generate insights for decision-making.
